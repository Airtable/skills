# Airtable Skills

Agent skills for Airtable, built to pair with the [Airtable MCP server](https://support.airtable.com/docs/using-the-airtable-mcp-server).

These skills follow the [agentskills.io](https://agentskills.io) spec.

## Installation

Using the [`skills` CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add airtable/skills
```

### Install a specific skill

```bash
npx skills add airtable/skills --skill airtable-filters
```

Or download all skills directly from the [latest release](https://github.com/airtable/skills/releases/latest).
